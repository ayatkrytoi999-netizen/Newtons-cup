# ☕ Остывающая чашка: виртуальная лаборатория

Интерактивная модель остывания тела по закону Ньютона. Работает прямо в браузере: один файл `index.html`, без библиотек и установки.

## Модель

T(t) = T_ср + (T₀ − T_ср) · e^(−kt)

- T₀ — начальная температура, °C
- T_ср — температура окружающей среды, °C
- k — коэффициент остывания, 1/мин
- t½ = ln 2 / k — время, за которое разность температур уменьшается вдвое

Для проверки рядом считается численное решение методом Эйлера: T(n+1) = T(n) − k · (T(n) − T_ср) · Δt.

## Что внутри

1. **Эксперимент 1. Зависимость температуры от времени.** Выбираете начальную температуру, считаете изменение во времени, получаете таблицу, график и анализ (начальная скорость, t½, погрешность метода Эйлера). Ползунок времени показывает, как остывает чашка.
2. **Эксперимент 2. Влияние температуры среды.** Добавляете до 6 температур среды, сравниваете графики и таблицы, лаборатория выделяет закономерности.
3. **Отчёт.** Кнопка «Сохранить в отчёт» собирает график, таблицу и выводы на отдельной вкладке для скриншота или печати.

## Запуск

Локально: скачайте репозиторий и откройте `index.html` в браузере.

Онлайн через GitHub Pages: Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save. Через минуту-две сайт откроется по ссылке выше.

## Технологии

HTML, CSS и JavaScript без зависимостей. Графики рисуются на canvas. Поддерживается светлая и тёмная тема, интерфейс адаптирован под телефон.
